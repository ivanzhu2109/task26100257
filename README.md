# fuzzyjoin

双来源模糊联接库（Go，纯进程内存，无外部依赖）。供上层融合任务直接调用：
对两份已清洗、已完成字段映射的名册，找出所有匹配键相似度不低于 0.85 的
跨来源记录对。本模块只负责完整找出候选，不负责合成主记录。

## 匹配规则

- 距离为码点级 Levenshtein 距离：插入、删除、替换一个 Unicode 码点代价均为 1，
  相邻码点交换不算一次编辑。
- 相似度 = 1 − 距离 / 两键较长者的码点数；阈值 0.85 按精确数学值判断
  （内部用整数运算 `3*maxLen >= 20*distance`，不做浮点舍入）。
  例如长度 20 的键距离 3 匹配、距离 4 排除。
- 匹配键为 1 至 64 个 Unicode 码点，不做大小写转换、去空白或规范化。
- 只返回跨来源配对；不进行传递合并；不限制每条记录的匹配数量。
- 相同键在两源分别出现 m、n 次时贡献 m×n 对，记录身份不丢失；
  每个符合条件的记录对恰好出现一次，每对附带精确编辑距离。

## 使用

```go
import "fuzzyjoin"

left := []fuzzyjoin.Record{
    {ID: "L1", Key: "acme-001"},
    {ID: "L2", Key: "acme-001"}, // 相同键对应多条记录，身份保留
}
right := []fuzzyjoin.Record{
    {ID: "R1", Key: "acme-002"},
}

// 流式消费：yield 返回 false 立即结束本次联接，不再计算剩余结果。
err := fuzzyjoin.Join(left, right, func(p fuzzyjoin.Pair) bool {
    fmt.Println(p.LeftID, p.RightID, p.Distance)
    return true
})

// 或者一次性收集（结果很大时请用流式接口）。
pairs, err := fuzzyjoin.JoinAll(left, right)
```

输入校验：键为空或超过 64 个码点、同一来源内记录 ID 重复、yield 为 nil，
均返回错误。结果顺序不限。

## 实现要点

- 左来源按不同键分组，建立三元组（trigram）倒排索引（排序数组，内存扁平）。
- 对每个右来源键用 q-gram 计数过滤产生候选，过高频的三元组跳过并从阈值中
  扣除其重数（数学上仍是无漏报的过滤）；候选用带剪枝的带状 DP 精确验证。
- 极端偏斜（如所有键几乎相同）时自动退化为按长度分桶的精确验证，保证正确性。
- 结果逐对产出，不累积；提前结束时立即返回，无后台计算。

## 性能

标准批次（每源 5 万条、键长 28–36 码点、80% 共享 8 码点前缀、6000 个
1–4 次编辑的变体对）：本机实测约 6 秒、峰值堆内存约 100 MiB
（验收上限 30 秒 / 256 MiB）。1 亿对潜在结果只消费前 1000 对时约 2 毫秒结束。
